# Team Project Chat C#
1. Turn on the server by selecting the port in the textbox and clicking start.
2. Press the 'R' (refresh) button near the lbUsers listbox to refresh the listbox and show all of the current users.
3. Turn on the client by connecting to the correct ipAddress/port. After that enter your login/password and register/login.
4. If your credentials are in the database you will be logged in immediately. If they are not and you are registering the administrator (server) will have to approve you.
5. After you successfully logged in, you can type either public or private messages to other users using the lbUsers on the client side.
6. To send a file, you also pick the recipients and press send file and pick a file to send.
7. After someone sent you a file, the program will notify you with a message box, in which you will say yes to downloading the file. Choose where to download it and it will be saved.
